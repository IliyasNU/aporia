# Independent audit of v1.0: findings and resolutions

Before release, an independent reviewer audited `release/v1.0.0` (functionality, security,
database integrity, authentication, email, recommendations, deployment) against the running
stack, the test suites and the code. This page lists every finding and what was done.
Regression tests for the fixes are in `backend/tests/test_audit_regressions.py` (and the
named frontend tests).

| #   | Severity | Finding                                                                                                                                 | Resolution                                                                                                                                                                                                                                 |
| --- | -------- | --------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| 1   | Medium   | Database errors were logged with all SQL parameters (an email and password hash appeared in a log); NUL characters in input caused 500s | **Fixed.** Engines use `hide_parameters=True`; the 500 handler logs only the class, SQLSTATE, constraint and stack frames of database errors, never their text; NUL characters in bodies (`RequestModel`), paths and query strings get 422 |
| 2   | Medium   | Reports about permanently deleted content could never be closed; the report list was capped at 200                                      | **Fixed.** Deletion commands and the 30-day purge close the reports of everything they remove; moderating a vanished target closes its reports; `GET /admin/reports` is paginated                                                          |
| 3   | Medium   | Any SMTP 5xx (wrong password, sender quota) failed every queued email permanently                                                       | **Fixed.** Only recipient refusals and per-message rejections are permanent; account-level errors are retried, and a batch stops at the first temporary error; `python -m app.cli requeue-failed-emails`                                   |
| 4   | Medium   | A published essay could be edited to an empty body                                                                                      | **Fixed.** 422 `empty_body`; drafts may still be empty                                                                                                                                                                                     |
| 5   | Low      | A website URL that grows when normalised (é → %C3%A9) caused a 500                                                                      | **Fixed.** The final URL length is validated                                                                                                                                                                                               |
| 6   | Low      | `List-Unsubscribe` was folded into unreadable encoded-words                                                                             | **Fixed.** Emails use a 998-character line policy; the test checks the raw bytes                                                                                                                                                           |
| 7   | Low      | Subscribe answered faster for addresses that got no email (timing hint)                                                                 | **Fixed.** The confirmation email is sent after the response (background task)                                                                                                                                                             |
| 8   | Low      | Parallel subscribe requests bypassed the resend throttle                                                                                | **Fixed.** `INSERT … ON CONFLICT` then `SELECT … FOR UPDATE`; the send time is recorded before sending                                                                                                                                     |
| 9   | Low      | `GET /me/following` loaded authors one by one (N+1)                                                                                     | **Fixed.** `contains_eager`; a test checks the query count                                                                                                                                                                                 |
| 10  | Low      | Recommendations took ~105 ms CPU per request                                                                                            | **Fixed.** Pruned greedy ranking with an identical result (checked against the plain definition on 20 random scenarios): ~36 ms for 300 candidates                                                                                         |
| 11  | Low      | Swagger UI loaded an unpinned CDN version on the app's origin                                                                           | **Fixed.** Exact version pinned; `API_DOCS_ENABLED=false` switches the page off                                                                                                                                                            |
| 12  | Low      | Confirmation emails carried the author's free-text display name to any address                                                          | **Fixed.** Neutral subject; the body names the author only by `@handle`                                                                                                                                                                    |
| 13  | Low      | The API port, if reachable, trusted any `X-Forwarded-For` and accepted chunked bodies past the size check                               | **Fixed.** Docker Compose no longer publishes the API port; only nginx reaches it (CI checks the port is closed)                                                                                                                           |
| 14  | Low      | Admins could not see what a report pointed at                                                                                           | **Fixed.** Admin reports include the article title or comment excerpt, its page and its moderation status                                                                                                                                  |
| 15  | Low      | A frontend test could time out on a busy machine                                                                                        | **Fixed.** Async test timeout raised to 5 s                                                                                                                                                                                                |
| 16  | Info     | Soft-deleted content and unsubscribed addresses were kept forever                                                                       | **Fixed.** Purged after 30 days (`DELETED_CONTENT_RETENTION_DAYS`)                                                                                                                                                                         |
| 16  | Info     | `safeNext` accepted encoded control characters                                                                                          | **Fixed.** Raw or encoded control characters and backslashes are refused                                                                                                                                                                   |
| 16  | Info     | The worker heartbeat was written even when the database was unreachable                                                                 | **Fixed.** Written only after a pass that reached the database                                                                                                                                                                             |
| 16  | Info     | `Message-ID` domain was hard-coded                                                                                                      | **Fixed.** Taken from `MAIL_FROM`                                                                                                                                                                                                          |
| 16  | Info     | Creating an essay reveals whether a slug already exists (also for drafts)                                                               | **Accepted.** Only the slug of a title is revealed, never content; documented in the changelog                                                                                                                                             |
| 16  | Info     | 10 failed logins per email in 5 minutes also block the real owner for up to 5 minutes                                                   | **Accepted.** Standard trade-off against password guessing; documented                                                                                                                                                                     |
| 16  | Info     | Follows and bookmarks use composite primary keys; ownership is checked in Python after loading                                          | **Accepted.** Composite keys are the uniqueness rule; ownership checks are covered by tests                                                                                                                                                |
| 17  | Info     | Documentation drift and `0.1.0` version numbers                                                                                         | **Fixed.** Docs updated; version 1.0.0                                                                                                                                                                                                     |

Things the audit checked and found correct: ownership rules, admin-only endpoints and the
401 sweep; CSRF middleware across 14 header variants; sessions (flags, hashing, revocation,
rotation, expiry); identical login answers and timing; safe Markdown, plain-text comments,
http(s)-only websites; the single visibility rule everywhere; idempotent follows and
bookmarks; the whole email flow; the recommendation formula, ordering and exclusions;
migrations up and down; compose port bindings, non-root images, log rotation and the
production `SECRET_KEY` check.
